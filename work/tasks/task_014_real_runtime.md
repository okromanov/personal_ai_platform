# TASK_014 — Реальная среда агента для ARC_CMP_003

## 1. Зачем это делаем

Существующий `StubRuntime` доказывает только границу [`ARC_CMP_003`](../../specifications/architecture_baseline.md#arc_cmp_003). Для результата [`m02`](../../milestones.md#m02) нужна выбранная и реально работающая среда агента.

## 2. Результат

[`ADR_006`](../../adr/adr_006_agent_environment_framework.md) принят после сравнения актуальных вариантов; выбранная среда подключена через `RuntimePort` к развёрнутому контуру без обхода контроля владельца.

## 3. Где мы сейчас

Контракт и StubRuntime поставлены [`TASK_003`](task_003_arc_003.md), но ADR остаётся proposed и реальная среда не подключена.

## 4. Что делать сейчас

### Агенту

1. Сравнить 2–3 актуальные среды на одном минимальном сценарии
2. Представить владельцу решение для [`ADR_006`](../../adr/adr_006_agent_environment_framework.md)
3. После решения добавить фактические пути и реализовать адаптер
4. Доказать работу через RuntimePort без обхода OwnerControl

## 5. План выполнения

- [ ] Сравнить варианты и принять [`ADR_006`](../../adr/adr_006_agent_environment_framework.md)
- [ ] Дополнить allowed_paths реальными путями
- [ ] Подключить выбранную среду через RuntimePort
- [ ] Написать TEST с реальным evidence
- [ ] Проверить границы контроля владельца

## 6. Состав

До выбора `allowed_paths` содержит только эту карточку. После решения в него включаются реальный адаптер, конфигурация и TEST.

## 7. Проверки и доказательства

Нужны автоматические контрактные проверки и evidence запуска выбранной среды в развёрнутом контуре. StubRuntime не является evidence этой TASK.

## 8. Готово когда

- ✅ [`ADR_006`](../../adr/adr_006_agent_environment_framework.md) принят владельцем
- ✅ Реальная среда выполняет задачу через RuntimePort
- ✅ Контроль владельца сохранён до выполнения
- ✅ TEST и evidence актуальны для точного SHA

## 9. Что будет дальше

[`TASK_015`](task_015_real_model_provider.md) подключит реального поставщика модели к выбранной среде.

## 10. Что это даёт владельцу

Помощник получает настоящую среду выполнения вместо тестовой имитации.
