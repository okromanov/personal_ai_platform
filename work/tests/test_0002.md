# TEST_0002 — Проверка качества, доказательств и автоматизации принятия

Автоматическая проверка. Действия владельца не требуются.

## 1. Назначение

Доказать, что средство оценки готовности использует декларативные профили, проверяет покрытие состава, не принимает неизвестное обязательное доказательство, привязывает доказательства к Git SHA и не даёт автоматизации по расписанию менять состояние репозитория.

## 2. Что проверяется

Набор модульных тестов покрывает реестр качества, разбор состава этапа, покрытие проектных TASK и TEST, метаданные доказательств, вычисление состояния, подтверждение владельца, переход принятия и границы суточной автоматизации только для чтения.

Проверка дополнительно контролирует отсутствие `contents: write` и команд записи Git в пути автоматизации по расписанию.

## 3. Автоматический запуск

```powershell
py -m unittest discover -s operations\tests -p "test_*.py"
```

## 4. Критерий успеха

Все модульные тесты проходят.

- Этап без профиля качества остаётся `not-ready`.
- Непокрытый состав блокирует принятие.
- Доказательство содержит Git SHA, среду и время.
- Неверное подтверждение владельца или несовпадение SHA блокирует переход принятия.
- Суточная автоматизация не имеет пути изменения репозитория.

## 5. Состав доказательства

`automated_evidence: unit_tests`. Результат сохраняется как отдельная запись доказательства и относится только к указанным Git SHA и среде. `spec_state` TEST остаётся `current`, а исход запуска хранится в поле `result`.
