# TEST_001 — Проверка модели документов и трассировки

Автоматическая проверка. Действия владельца не требуются.

## 1. Назначение

Доказать структурную целостность основы: типизированные идентификаторы, отдельные источники истины, точные связи, полнота обязательных полей угроз, корректный состав этапа и отсутствие устаревших предположений.

## 2. Что проверяется

`check.py --all` проверяет структуру, метаданные, типизированную трассировку, правила документов, этапы, TASK, TEST, реестр качества, модель принятия, автоматизацию, ссылки, производные представления и секреты.

Для профиля основы `project_checks` является общим доказательством только структурной и нормативной целостности документов и инструментов. Он не доказывает реализацию продуктовых BR/SYS/SEC/INF. Этап [`m01`](../../milestones.md#m01) не объявляет их составом реализации.

## 3. Автоматический запуск

```powershell
py -3.12 operations\scripts\documents\generate.py --all
py -3.12 operations\scripts\documents\check.py --all
```

## 4. Критерий успеха

Все группы проверки успешны. Оборванные, повторные и отсутствующие обязательные связи отсутствуют. Состав этапа разрешается в существующие идентификаторы. Поля угроз заполнены, автоматизация остаётся только читающей, а производная матрица воспроизводима.

## 5. Состав доказательства

`automated_evidence: project_checks`. Каждый запуск создаёт отдельную запись доказательства с Git SHA, временем и средой. `spec_state` этого документа остаётся `current`, а фактический исход хранится только в поле `result`.
