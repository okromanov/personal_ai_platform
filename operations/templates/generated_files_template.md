# Шаблон генерируемых файлов

Генерируемые файлы — это документы, которые собираются автоматически из состояния проекта и не редактируются вручную. Все генерируемые файлы должны начинаться с комментария о невозможности ручного редактирования, за которым следуют YAML frontmatter. Для [`tasks.md`](../../tasks.md) и [`project_status.md`](../../project_status.md) дополнительно принята **отформатированная таблица метаданных**, описанная ниже; она не обязательна для остальных генерируемых файлов (`generated/*`), у которых своя структура, задаваемая собственным генератором.

## Структура

```markdown
<!-- generated file: do not edit manually -->
---
id: <generated_file_id>
type: <generated_type>
generation_state: generated
version: 1.0
---

# <Заголовок>

| Параметр | Значение |
|---|---|
| Параметр 1 | Значение 1 |
| Параметр 2 | Значение 2 |

<Остальное содержимое файла>
```

## Обязательные поля frontmatter

- `id`: уникальный идентификатор для генерируемого файла (например, `task_index`, `project_status_current`)
- `type`: тип документа с префиксом `generated_` (например, `generated_task_index`, `generated_owner_status`)
- `generation_state`: всегда `generated`
- `version`: номер версии (установить `1.0`)

## Таблица метаданных

Таблица помещается сразу после заголовка `# <Название>` и служит для быстрого отображения ключевых параметров файла. Параметры зависят от типа документа:

### Для [`tasks.md`](../../tasks.md) (task_index)

| Параметр | Значение |
|---|---|
| Статус очереди | Количество задач / текущая позиция |
| Текущая задача | ID и название текущей TASK или "—" |
| Состояние | Статус текущей задачи |
| Следующий исполнитель | Агент, владелец или —  |

### Для [`project_status.md`](../../project_status.md) (project_status_current)

| Параметр | Значение |
|---|---|
| Текущий этап | ID и название этапа |
| Текущая проектная задача | ID и название или — |
| Место в очереди проекта | Позиция / общее количество |
| Следующий исполнитель | Кто действует дальше |

## Регенерация

Файлы регенерируются командой:

```bash
python3.12 operations/scripts/documents/generate.py --all
```

Никогда не редактируйте эти файлы вручную — все изменения будут перезаписаны при следующей регенерации.
