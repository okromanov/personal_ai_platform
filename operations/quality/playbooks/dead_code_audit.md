# Поиск мёртвого кода

## Запуск

```bash
python3.12 operations/scripts/quality/code_analyzer.py
```

Команда является частью полного quality-suite и запускает настроенный Vulture-анализ. Ruff отдельно проверяет неиспользуемые импорты и локальные имена.

## Разбор результата

Каждое совпадение читается в контексте. Динамический импорт, protocol hook, entrypoint и test fixture могут выглядеть неиспользуемыми статически. Удаление допустимо только после проверки вызовов и тестов поведения.

## Критерий успеха

Новые подтверждённые недостижимые ветви отсутствуют; suppression узкий и содержит проверяемую причину. Этот playbook не заявляет метрики сложности или дублирования, которых нет в каноническом gate.
