# Триггеры и процедуры угроз

Этот документ организует, как каждая потенциальная угроза из модели (см. [`specifications/threat_model.md`](../../specifications/threat_model.md)) должна быть обнаружена, проверена, и какие действия должны быть предприняты при обнаружении.

## 1. Назначение

Для каждой угрозы в модели определяется:

- **Триггер обнаружения**: Какое событие, ошибка, или аномалия указывает на возможность угрозы
- **Процедура проверки**: Как мы проверяем, что угроза действительно произошла
- **Действия откликаемые**: Какие действия должны быть предприняты немедленно
- **Обзор**: Кто и когда должен провести полный обзор

## 2. Карта триггеров угроз

### Неавторизованный запуск задачи (`THR_001`)

| Параметр | Значение |
|---|---|
| **Триггер** | Попытка создать задачу без проверки личности |
| **Признак** | Логовая запись о задаче без соответствующей записи авторизации |
| **Проверка** | Проверить [`SEC_CTL_001`](../../specifications/system_specification.md#sec_ctl_001) активен на входе |
| **Действие** | Отклонить задачу, залогировать попытку |
| **Обзор** | Если обнаружено: немедленный анализ попытки |

### Обход аварийного выключателя (`THR_002`)

| Параметр | Значение |
|---|---|
| **Триггер** | Задача выполнилась, когда аварийный выключатель был активен |
| **Признак** | Временные метки: аварийный выключатель ON, но задача завершилась |
| **Проверка** | Проверить [`SEC_CTL_002`](../../specifications/system_specification.md#sec_ctl_002) приоритет выключателя |
| **Действие** | Откатить задачу, изолировать выключатель |
| **Обзор** | Критичный обзор: немедленно |

### Расширение полномочий среды или инструмента (`THR_003`)

| Параметр | Значение |
|---|---|
| **Триггер** | Инструмент запросил полномочия выше его класса воздействия |
| **Признак** | Логовая запись о попытке повышения полномочий |
| **Проверка** | Проверить [`SEC_CTL_003`](../../specifications/system_specification.md#sec_ctl_003) и [`SEC_CTL_007`](../../specifications/system_specification.md#sec_ctl_007) |
| **Действие** | Отклонить полномочия, вызвать исключение |
| **Обзор** | Если повторяется: обзор интеграции инструмента |

### Внедрение инструкции через недоверенное содержимое (`THR_004`)

| Параметр | Значение |
|---|---|
| **Триггер** | Содержимое файла или внешнего источника содержит инструкции |
| **Признак** | Обнаружены специальные символы или команды в недоверенных данных |
| **Проверка** | Проверить [`SEC_CTL_004`](../../specifications/system_specification.md#sec_ctl_004) (недоверенное содержимое изолировано) |
| **Действие** | Обработать содержимое как данные, не выполнять инструкции |
| **Обзор** | Периодичный обзор: после каждого использования недоверенного источника |

### Компрометация секрета (`THR_005`)

| Параметр | Значение |
|---|---|
| **Триггер** | Секрет обнаружен в Git, логах или памяти |
| **Признак** | Secret scanning инструмент обнаружил потенциальный секрет |
| **Проверка** | Проверить [`SEC_CTL_005`](../../specifications/system_specification.md#sec_ctl_005) (изоляция секретов) |
| **Действие** | Немедленно ротировать секрет, удалить из истории |
| **Обзор** | Немедленный анализ: источник утечки |

### Пересечение области данных (`THR_006`)

| Параметр | Значение |
|---|---|
| **Триггер** | Запрос данных пересекает область (работа/личное) |
| **Признак** | Логовая запись показывает доступ вне разрешённой области |
| **Проверка** | Проверить [`SEC_CTL_006`](../../specifications/system_specification.md#sec_ctl_006) (изоляция областей) |
| **Действие** | Отклонить доступ, залогировать попытку |
| **Обзор** | Если один раз: логируется; если повторяется: обзор полномочий |

### Вредоносный файл, анализатор или код (`THR_007`)

| Параметр | Значение |
|---|---|
| **Триггер** | Файл помечен как вредоносный или выполнение кода вызывает ошибку |
| **Признак** | Antivirus или static analysis обнаружит проблему |
| **Проверка** | Проверить [`SEC_CTL_009`](../../specifications/system_specification.md#sec_ctl_009) (изолированное выполнение) |
| **Действие** | Изолировать исполнение, отклонить результаты |
| **Обзор** | Анализ: источник вредоноса |

### Нежелательное или повторное внешнее действие (`THR_008`)

| Параметр | Значение |
|---|---|
| **Триггер** | Внешнее действие выполнилось дважды или в неправильное время |
| **Признак** | Дублирующиеся записи в целевой системе или уведомление о повтора |
| **Проверка** | Проверить [`SEC_CTL_008`](../../specifications/system_specification.md#sec_ctl_008) (контроль чувствительных действий) |
| **Действие** | Откатить второе действие, уведомить владельца |
| **Обзор** | Периодичный обзор: логи повторений |

### Обход обязательной сетевой политики (`THR_009`)

| Параметр | Значение |
|---|---|
| **Триггер** | Трафик вне разрешённого (firewall alert) |
| **Признак** | Firewall logs или network monitoring обнаружит нарушение |
| **Проверка** | Проверить [`SEC_CTL_010`](../../specifications/system_specification.md#sec_ctl_010) (явный трафик) |
| **Действие** | Заблокировать трафик, изолировать процесс |
| **Обзор** | Немедленный анализ: источник и цель |

### Компрометация цепочки поставки (`THR_010`)

| Параметр | Значение |
|---|---|
| **Триггер** | Dependency scanner обнаружит уязвимость в библиотеке |
| **Признак** | CVE уведомление или аудит зависимостей |
| **Проверка** | Проверить версии используемых компонентов |
| **Действие** | Обновить компонент или изолировать его использование |
| **Обзор** | Еженедельный скан зависимостей |

### Неограниченный расход ресурсов (`THR_011`)

| Параметр | Значение |
|---|---|
| **Триггер** | Использование CPU, памяти или API квот превышает нормальные пределы |
| **Признак** | Monitoring alert или timeout ошибка |
| **Проверка** | Проверить [`SEC_CTL_012`](../../specifications/system_specification.md#sec_ctl_012) (ограничения на ресурсы) |
| **Действие** | Остановить задачу, изолировать процесс |
| **Обзор** | Анализ: причина превышения |

### Потеря постоянного состояния (`THR_012`)

| Параметр | Значение |
|---|---|
| **Триггер** | Запись памяти не найдена или база данных недоступна |
| **Признак** | Ошибка чтения из долговременной памяти |
| **Проверка** | Проверить [`SEC_CTL_013`](../../specifications/system_specification.md#sec_ctl_013) (резервное копирование) |
| **Действие** | Восстановить из резервной копии, уведомить владельца |
| **Обзор** | Немедленный анализ: причина потери |

### Утечка через журналирование и доказательства (`THR_013`)

| Параметр | Значение |
|---|---|
| **Триггер** | Чувствительная информация в логах или доказательствах |
| **Признак** | Manual audit или secret scanning в логах |
| **Проверка** | Проверить [`SEC_CTL_014`](../../specifications/system_specification.md#sec_ctl_014) (минимизация логов) |
| **Действие** | Удалить/маскировать чувствительные логи |
| **Обзор** | Еженедельный аудит логов |

### Передача данных неподходящему поставщику модели (`THR_014`)

| Параметр | Значение |
|---|---|
| **Триггер** | Данные отправлены к неавторизованному поставщику API |
| **Признак** | Логовая запись показывает обращение к неразрешённому endpoint |
| **Проверка** | Проверить [`SEC_CTL_015`](../../specifications/system_specification.md#sec_ctl_015) (допуск к модели) |
| **Действие** | Отклонить запрос, блокировать endpoint |
| **Обзор** | Анализ: источник ошибочного обращения |

### Небезопасное обновление или развёртывание (`THR_015`)

| Параметр | Значение |
|---|---|
| **Триггер** | Обновление не прошло автоматические проверки |
| **Признак** | CI/CD pipeline отклонил обновление |
| **Проверка** | Проверить тесты и проверки целостности |
| **Действие** | Заблокировать развёртывание, требовать исправления |
| **Обзор** | Анализ: почему проверки не прошли |

### Ошибочное автономное расписание (`THR_016`)

| Параметр | Значение |
|---|---|
| **Триггер** | Плановая задача выполнилась в неправильное время или по ошибке |
| **Признак** | Логовая запись показывает неправильное время выполнения |
| **Проверка** | Проверить [`SEC_CTL_017`](../../specifications/system_specification.md#sec_ctl_017) (безопасное расписание) |
| **Действие** | Откатить результаты, отключить расписание для проверки |
| **Обзор** | Анализ: причина ошибки в расписании |

### Возврат устаревшей или удалённой памяти (`THR_017`)

| Параметр | Значение |
|---|---|
| **Триггер** | Система вернула запись после удаления или воскресила |
| **Признак** | Дублирующаяся запись или невозможная дата создания |
| **Проверка** | Проверить логи удаления и восстановления |
| **Действие** | Удалить восстановленную запись, проверить целостность памяти |
| **Обзор** | Анализ: как произошло восстановление |

### Саморасширение агента или автоматизации (`THR_018`)

| Параметр | Значение |
|---|---|
| **Триггер** | Агент создал новый инструмент или полномочие без разрешения |
| **Признак** | Новый инструмент в registry без явного добавления |
| **Проверка** | Проверить [`SEC_CTL_002`](../../specifications/system_specification.md#sec_ctl_002) (аварийный выключатель) и границы |
| **Действие** | Немедленно отключить агент, удалить несанкционированные изменения |
| **Обзор** | Критичный анализ: источник саморасширения |

### Компрометация административного доступа (`THR_019`)

| Параметр | Значение |
|---|---|
| **Триггер** | Попытка доступа с чужими административными учётными данными |
| **Признак** | Логовая запись о неудачной авторизации с admin токеном |
| **Проверка** | Проверить [`SEC_CTL_020`](../../specifications/system_specification.md#sec_ctl_020) (защита админа) |
| **Действие** | Ротировать admin учётные данные немедленно |
| **Обзор** | Немедленный анализ: источник утечки учётных данных |

## 3. Типы обзоров

### Немедленный обзор (Critical)

Выполняется сразу при обнаружении угрозы:
- [`THR_002`](../../specifications/threat_model.md#thr_002), [`THR_005`](../../specifications/threat_model.md#thr_005), [`THR_018`](../../specifications/threat_model.md#thr_018), [`THR_019`](../../specifications/threat_model.md#thr_019)

Владелец уведомляется немедленно.

### Обзор по обнаружению (High Priority)

Выполняется в течение одного рабочего дня:
- [`THR_009`](../../specifications/threat_model.md#thr_009), [`THR_012`](../../specifications/threat_model.md#thr_012), [`THR_015`](../../specifications/threat_model.md#thr_015)

Владелец информируется в течение часа.

### Регулярный обзор (Periodic)

Выполняется по графику:
- [`THR_004`](../../specifications/threat_model.md#thr_004), [`THR_008`](../../specifications/threat_model.md#thr_008), [`THR_010`](../../specifications/threat_model.md#thr_010), [`THR_013`](../../specifications/threat_model.md#thr_013), [`THR_014`](../../specifications/threat_model.md#thr_014), [`THR_016`](../../specifications/threat_model.md#thr_016), [`THR_017`](../../specifications/threat_model.md#thr_017)

Еженедельно или ежемесячно в зависимости от критичности.

## 4. Процедура реагирования на угрозу

1. **Обнаружение**: Триггер срабатывает, система логирует событие
2. **Изоляция**: Процесс или компонент немедленно изолируется
3. **Уведомление**: Владелец получает alert в зависимости от типа
4. **Анализ**: Проверяется, действительно ли произошла угроза
5. **Действие**: Применяются необходимые меры (откат, ротация, обновление)
6. **Обзор**: Проводится полный анализ (для критичных - немедленно)
7. **Документация**: Результаты фиксируются в логе инцидентов
8. **Предотвращение**: Реализуется мера для предотвращения повторения
