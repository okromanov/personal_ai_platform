# Политика лицензирования и распространения

## 1. Текущий режим

Репозиторий является частным персональным проектом и не предназначен для публикации или передачи третьим лицам. Отсутствие корневого `LICENSE` означает, что разрешение на копирование, изменение и распространение кода не предоставляется; для текущего закрытого режима отдельная open-source лицензия не нужна.

## 2. Зависимости и артефакты

- прямые dev-зависимости задаются в [`requirements_dev.in`](../quality/requirements_dev.in);
- полный транзитивный состав и SHA-256 хеши фиксируются в [`requirements_dev.txt`](../quality/requirements_dev.txt);
- CI проверяет уязвимости полного lock-файла, строит контейнер из закреплённого base digest и сохраняет SPDX JSON SBOM как SHA-bound artifact;
- сторонние компоненты сохраняют собственные лицензии; эта политика не переопределяет их условия.

## 3. Условие публикации

До любой публичной публикации, передачи копии или предоставления внешним участникам владелец обязан отдельным решением:

1. выбрать лицензию проекта и добавить корневой `LICENSE`;
2. проверить совместимость лицензий всех распространяемых зависимостей по SBOM;
3. определить, какие документы, секреты, конфигурация и данные исключаются из поставки;
4. провести security и license review на точном release SHA.

Без выполнения этих условий допустим только текущий частный режим; CI-артефакт SBOM является evidence состава, но сам по себе не разрешает распространение.
