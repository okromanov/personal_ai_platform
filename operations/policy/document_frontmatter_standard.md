# Стандарт frontmatter для документов — архивная страница

Этот документ больше не задаёт правила. Он сохранён как стабильная цель старых ссылок.

Действующие источники:

- допустимые состояния, `applicability`, исполнители и Python-команды — [`document_contracts.json`](../document_contracts.json);
- правила создания и изменения документов — [`change_process.md`](../change_process.md);
- блокирующая реализация правил — [`check.py`](../scripts/documents/check.py);
- структура конкретного типа — зарегистрированный шаблон из [`template_registry.json`](../template_registry.json).

При расхождении этой архивной страницы с действующими источниками применяется действующий источник.
