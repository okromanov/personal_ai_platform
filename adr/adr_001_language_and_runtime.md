# ADR_001 — Основной язык реализации

## 1. Назначение

Зафиксировать основной язык прикладной реализации и инструментов проекта, не запрещая обоснованный другой язык для отдельного компонента.

## 2. Контекст

Платформе нужны интеграции с моделями, файлами и данными, автоматизация, тесты и работа в среде разработки и рабочей среде. Один основной язык уменьшает эксплуатационную сложность.

## 3. Решение

Использовать Python 3.12+ как основной язык ядра платформы, переходных слоёв и автоматизации проекта. Особенности операционной системы изолируются в небольших скриптах. Другой язык допустим только при конкретной технической выгоде, которую нельзя разумно получить в основном наборе технологий.

## 4. Альтернативы

- TypeScript — сильный вариант для веб-интерфейса, но не даёт причины заранее вводить вторую основную среду выполнения.
- Go/Rust — полезны для отдельных системных компонентов, но увеличивают сложность без текущего обязательного сценария.

## 5. Последствия

- единый основной набор инструментов для приложения и автоматизации;
- широкий выбор библиотек для моделей, данных и документов;
- необходимость отдельно доказывать совместимость с Linux, а не полагаться на локальную среду Windows.

## 6. Проверка

Воспроизводимые команды тестов и запуска не зависят от IDE и выполняются в поддерживаемой среде Python.
