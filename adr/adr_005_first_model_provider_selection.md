# ADR_005 — Выбор первого поставщика модели

## 1. Назначение

Зафиксировать Anthropic Claude (доступ через прямой API либо через посреднический канал доступа) как первоначального кандидата на роль первого поставщика модели для проверки в [`m02`](../milestones.md#m02), не подменяя сравнение вариантов и решение владельца.

## 2. Контекст

[`ADR_003`](adr_003_model_provider_interface.md#adr_003) определяет интерфейс `ModelProvider` для независимости от поставщика. Первоначальная реализация должна работать с конкретной моделью. Claude включён в план сравнительного прототипа как рабочая гипотеза по следующим причинам:

- Высокое качество рассуждения (reasoning) для сложных задач
- Надёжный API с хорошей документацией
- Политика использования данных соответствует принципу владения данными
- Доступные ограничения и контроль ограничений бюджета
- Совместимость с долгоживущим контекстом (memory requirements)

Владелец работает из России: прямой API Anthropic/OpenAI недоступен без VPN, а оплата иностранной картой не гарантирована. `ModelProvider` уже изолирует ядро от способа доступа, поэтому канал доступа к модели — отдельное решение внутри этого ADR, а не отдельный ADR: сама модель (Claude) может остаться неизменной, даже если меняется способ до неё достучаться.

## 3. Предлагаемое решение

В [`m02`](../milestones.md#m02) включить **Anthropic Claude** (актуальную доступную версию) в сравнение 2–3 вариантов и использовать его для одного минимального прототипа через:

1. **Интерфейс:** `ModelProvider` контракт (не прямые вызовы Claude SDK)
2. **Конфигурация:** API ключ, модель и канал доступа выбираются через переменные окружения
3. **Канал доступа:** сравнить как минимум два способа достучаться до Claude без VPN и с оплатой, доступной владельцу — посреднический мультипровайдерный API (например, OpenRouter) и российский посреднический API-провайдер (прокси доступа к Claude/GPT с оплатой в РФ, конкретный поставщик определяется отдельным evidence-сравнением, а не фиксируется этим ADR)
4. **Резервный путь:** Контракт позволяет добавить второго поставщика модели или сменить канал доступа позже без переписывания ядра
5. **Тестирование:** тестовый mock-поставщик для детерминированных проверок.

Переход `proposed → accepted` разрешён только после сравнительного evidence по критериям [`m02`](../milestones.md#m02) и явного решения владельца. До этого документ не означает выбор Claude или конкретного канала доступа для [`m02`](../milestones.md#m02)–[`m06`](../milestones.md#m06).

## 4. Альтернативы

| Вариант | Преимущества | Недостатки |
|---------|-------------|-----------|
| **Claude, прямой API (кандидат)** | Качество рассуждений, совместимость, политика данных | Недоступен из России без VPN; оплата иностранной картой не гарантирована |
| **Claude через OpenRouter (кандидат)** | Один ключ на несколько моделей (Claude/GPT/др.), более широкий выбор способов оплаты (в т.ч. крипта) | Дополнительный посредник в цепочке доверия и задержки |
| **Российский посреднический API-провайдер (кандидат)** | Оплата в рублях без VPN, отсутствие прямого договора с иностранным поставщиком | Устойчивость и политика конкретного посредника не проверены; требует отдельного evidence-сравнения провайдеров |
| OpenAI | Зрелый API и сильные модели | Та же проблема доступа/оплаты, что и у прямого Claude API |
| Open-source модель | Независимость и локальный путь | Требуются инфраструктура и проверка качества |
| Не выбирать сейчас | Максимальная гибкость | Блокирует разработку m02 |

## 5. Последствия

**Положительные:**
- [`ADR_003`](adr_003_model_provider_interface.md#adr_003) контракт остаётся чистым (не привязан к Claude)
- [`m02`](../milestones.md#m02) получает конкретного кандидата для воспроизводимого сравнения
- Резервный поставщик добавляется через тот же интерфейс

**Отрицательные:**
- Прототип сравнения частично зависит от Claude (в рамках интерфейса)
- Затраты на API во время разработки и тестирования
- Зависимость от доступности Anthropic API

## 6. Проверка

- [ ] Claude и минимум один альтернативный вариант проверены на одном сценарии и одной scorecard.
- [ ] Минимум два канала доступа к Claude (OpenRouter и российский посреднический API-провайдер) сравнены по доступности без VPN, оплате и задержке.
- [ ] `ModelProvider` работает с каждым проверенным вариантом без прямых импортов SDK в бизнес-коде.
- [ ] Переменные окружения позволяют менять ключ, модель и канал доступа без изменения кода.
- [ ] Mock-поставщик проходит тот же контракт.
- [ ] Evidence и решение владельца зафиксированы до смены `decision_state`.
